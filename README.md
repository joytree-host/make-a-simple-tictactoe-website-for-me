# Tic-Tac-Toe

A complete, working tic-tac-toe game with score tracking and a clean, modern interface.

## Features

- Full 3x3 tic-tac-toe gameplay
- Win detection with visual highlighting
- Draw detection
- Persistent score tracking (X wins, O wins, draws)
- Turn indicator
- Responsive design for mobile and desktop
- Reset game and reset scores buttons

## How to Play

1. Player X goes first
2. Take turns placing your marks on the 3x3 grid
3. Get three of your marks in a row (horizontally, vertically, or diagonally) to win!
4. If the board fills up with no winner, it's a draw

## Files

- `index.html` - Game structure and layout
- `styles.css` - Styling and responsive design
- `script.js` - Game logic and interactivity

## How to Run

Simply open `index.html` in a web browser. No server or build step required.

## Controls

- Click on any empty cell to place your mark
- **Reset Game** - Starts a new game while keeping scores
- **Reset Scores** - Resets all scores and starts a new game
